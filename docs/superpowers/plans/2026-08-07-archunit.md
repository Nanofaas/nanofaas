# ArchUnit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convertire l'architettura implicita del control-plane (core + 9 moduli SPI) in regole ArchUnit eseguite da `./gradlew test`, con gate verde sul codice attuale.

**Architecture:** Regole core in `CoreArchitectureTest` (nel modulo control-plane), regola di isolamento per modulo in un `ArchitectureTest` nei test di ciascun modulo (nessun modulo dedicato: i moduli sono opzionali nel build del core). Prima dello scrivere le regole, le 8 classi di sync-queue che vivono nel namespace del core vengono spostate nel namespace del proprio modulo. Una regola di ownership del namespace (R6) usa una condizione ArchUnit custom sulla locazione del class file.

**Tech Stack:** JUnit 5, `com.tngtech.archunit:archunit-junit5:1.4.1`, Gradle 9.3.1, Java 25.

## Global Constraints

- Solo cambiamenti behavior-preserving; nessuna logica toccata nello spostamento sync-queue (solo package declaration + import).
- Nessun `@SuppressWarnings`/NOSONAR salvo casi documentati.
- Regole ArchUnit nominate con `@ArchTest`, `.as("<nome descrittivo>")` e commento sull'invarianza protetta.
- Commit in inglese, SENZA trailer Co-Authored-By (repo single-author). Comunicazione in italiano.
- Gate per task: `./gradlew test --no-parallel` completo (tutti i moduli) + `gitnexus_detect_changes` prima di ogni commit.
- Se una regola risulta violata dal codice attuale (oltre R6/sync-queue già pianificato): NON modificare il codice — fermarsi e riportare all'utente.
- Regole del piano: R1 cicli, R2 api entry point, R3 core↛moduli, R4 layer bassi↛service, R5′ isolamento moduli con allowlist, R6 ownership namespace (dettagli in ogni task).
- Le verifiche nel piano sono state fatte sul codice al 2026-08-07: service↛api, dispatch↛service, execution↛service, deployment↛service, core↛moduli, moduli↛moduli (tutte vuote).

- [ ] **Step 1: Scrivere le regole mancanti**

Estendere `CoreArchitectureTest.java` con:

```java
    // R2: api è l'entry point: le classi fuori da api non devono dipendere da api.
    @ArchTest
    static final ArchRule api_is_the_only_entry_point =
            noClasses()
                    .that().resideOutsideOfPackage("..controlplane.api..")
                    .should().dependOnClassesThat().resideInAPackage("..controlplane.api..")
                    .as("the api layer is the entry point: lower layers must not reach back into it");

    // R3: il core non dipende mai dai moduli (optionalità SPI: il core funziona senza).
    @ArchTest
    static final ArchRule core_does_not_depend_on_modules =
            noClasses()
                    .that().resideInAPackage("..controlplane..")
                    .should().dependOnClassesThat().resideInAPackage("..modules..")
                    .as("the core must work without optional modules (SPI)");

    // R4: la direzione è api -> service -> dispatch: i layer bassi non risalgono a service.
    @ArchTest
    static final ArchRule lower_layers_do_not_depend_on_service =
            noClasses()
                    .that().resideInAnyPackage(
                            "..controlplane.dispatch..",
                            "..controlplane.execution..",
                            "..controlplane.deployment..")
                    .should().dependOnClassesThat().resideInAPackage("..controlplane.service..")
                    .as("dispatch, execution and deployment must not depend on service");

    // R6: il namespace controlplane appartiene al core — le classi che vi risiedono
    // devono avere il class file sotto platform/control-plane/.
    @ArchTest
    static final ArchRule controlplane_namespace_is_owned_by_core =
            noClasses()
                    .that().resideInAPackage("it.unimib.datai.nanofaas.controlplane..")
                    .should(haveSourceInCoreModule())
                    .as("classes in the controlplane namespace must live in the control-plane module");

    private static ArchCondition<JavaClass> haveSourceInCoreModule() {
        return new ArchCondition<>("have their class file under the control-plane module") {
            @Override
            public void check(JavaClass item, ConditionEvents events) {
                String path = item.getSourceCodeLocation().getSourceCodePath();
                if (!path.contains("/platform/control-plane/")) {
                    events.add(SimpleConditionEvent.violated(item,
                            item.getDescription() + " does not live in the control-plane module (" + path + ")"));
                }
            }
        };
    }
```

Aggiornare gli import statici della classe con:

```java
package it.unimib.datai.nanofaas.modules.asyncqueue.architecture;

import com.tngtech.archunit.core.domain.JavaClass;
import com.tngtech.archunit.junit.AnalyzeClasses;
import com.tngtech.archunit.junit.ArchTest;
import com.tngtech.archunit.lang.ArchRule;

import static com.tngtech.archunit.lang.syntax.ArchRuleDefinition.noClasses;

@AnalyzeClasses(packages = "it.unimib.datai.nanofaas.modules.asyncqueue..")
class ArchitectureTest {

    // R5': isolamento SPI. Un'estensione tra moduli è una decisione esplicita:
    // aggiungere una riga ignoreDependency(origin, target) con commento per ogni coppia sanzionata.
    @ArchTest
    static final ArchRule does_not_depend_on_other_modules =
            noClasses()
                    .that().resideInAPackage("..modules.asyncqueue..")
                    .should().dependOnClassesThat().resideInAPackage("..modules..")
                    .ignoreDependency(
                            JavaClass.Predicates.resideInAPackage("..modules.asyncqueue.."),
                            JavaClass.Predicates.resideInAPackage("..modules.asyncqueue.."))
                    .as("module must not depend on other modules (SPI isolation)");
}
```
